# Старые ссылки

В `go-mini/` лежат короткие перенаправления для прежних адресов страниц mini.
GitHub Pages создаёт их по полю `permalink`, поэтому ссылки из Stepik продолжают работать.
Параметры страницы и выбранный шаг сохраняются.

Сами уроки находятся в [папке курса](../courses/305666-go-mini/README.md).
Список соответствий: [legacy-paths.json](../courses/305666-go-mini/legacy-paths.json).
Обновить перенаправления: `node scripts/organize-go-mini.mjs`.
