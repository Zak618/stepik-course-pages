В каждом модуле `lesson-01-step-01.html` означает первый шаг первого урока.
`lesson-01-preview.html` открывает просмотр всего урока.
Второй модуль также содержит раннюю версию первого урока; актуальная отмечена `v2`.
В шестом модуле `pro-ticket.html` содержит билет с промокодом.

Общие стили, анимации и тексты уроков находятся в корневой папке `assets/go-mini-*`.
Скрипты проверки и публикации остаются в `scripts/`.
Старые адреса сохранены через [перенаправления](../../compat/README.md), дублировать уроки в корне не нужно.
