# Версии курса

Локальный черновик нового шага введения. В Stepik пока не опубликован.
Место в уроке: перед шагом «Что впереди».

```sh
node scripts/go-pro-max-introduction/build-versions.mjs
node scripts/go-pro-max-introduction/preview-versions.mjs
```

Просмотр: <http://localhost:8812/>.

Версии и короткий список изменений находятся в `releases.mjs`.
Добавьте новую запись в начало списка и выполните сборку.
Новая версия появится первой, прошлые записи сохранятся ниже.
На иллюстрации летят карточки с номерами из истории, без поясняющих надписей.
Наведение и фокус останавливают движение. При выключенной анимации в настройках
устройства карточки показаны неподвижно.

`picture.css` и `picture.js` отвечают за иллюстрацию. `picture.html`,
`index.html` и `publication.json` создаются при сборке, вручную их менять не нужно.
В `publication.json` подготовлен текст для Stepik. Только иллюстрация находится
во фрейме высотой 240 px. История версий идёт обычным текстом под ней.
Публикация этого черновика требует отдельного подтверждения.
