# Подводим итоги

Финальный модуль Go-шечки Pro MAX. [Открыть урок в Stepik](https://stepik.org/lesson/2744253/step/1?unit=2784768).

Один урок и четыре шага. Итоги с автоматической анимацией, свободный ответ об обучении, Telegram и два варианта продолжения. Анимация без кнопок показывает путь заказа через Vue, Go и PostgreSQL. Начинается при появлении на экране и останавливается на результате. При ограничении движения сразу показан результат.

Второй шаг имеет штатный тип `free-answer` и нулевую стоимость в баллах. Ответ пишется в обычном редакторе Stepik, вне фрейма. В локальном просмотре показан его макет без отправки данных. Копирование ответа и дублирующая форма не нужны.

```sh
node scripts/go-pro-max-finale/build.mjs
node scripts/go-pro-max-finale/preview.mjs
```

Открыть <http://localhost:8810/>.

Проверка на компьютере и телефоне

```sh
node scripts/go-pro-max-finale/check.mjs
```

Тексты и разметка в `content.mjs`, оформление в `finale.css`, анимации в `finale.js`. HTML собирается автоматически. Снимок актуальной программы и экспорт будущих шагов находятся в `.local-publication/go-pro-max-finale-draft/`.

Внешние карточки используют префикс `gpmx-finale-`. Класс `course-card` зарезервирован стилями Stepik: он задаёт сетку 324 × 210 px и ломает текст урока. При проверке нативного HTML нужно подключать стили Stepik, а не только стили локального просмотра.

Модуль добавлен 25 ноября 2026 года через аккаунт WEB HACKER. Теперь в курсе 29 модулей и 159 уроков. Прежние 158 уроков и настройки курса сохранены. ID модуля, урока и шагов находятся в `publication.json`.

В рекомендациях две самые дорогие опубликованные программы после исключения Go. React (pro) и FullStack Pro MAX. Стоимость сверена со Stepik, но в текст урока не вписана. Пересечение программ отмечено в карточках. Цены и состав разделов сохранены в локальных `prices.json` и `premium-courses.json`.
