Что изучим

Каждая тема
пригодится в проекте.

Сначала разберём основы. Затем соединим язык, базу данных и интерфейс.

GoПервые программы на Go

Установим Go и запустим первую программу. Разберём переменные, строки, условия, циклы, коллекции и функции. Потом перейдём к структурам, методам и интерфейсам.

HTTPСервер, ошибки и тесты

Научимся читать файлы, работать с ошибками и проверять код тестами. Разберём горутины и каналы. Напишем HTTP API, которое принимает запросы и возвращает JSON.

SQLGit, SQL и Docker

Будем сохранять историю кода в Git, писать SQL и работать с PostgreSQL из Go. Научимся запускать приложение и базу через Docker Compose.

GoСервис доставки на Go

Добавим каталог, регистрацию и вход, корзину и оформление заказа. Разберём права доступа, статусы и транзакции. Проверим, что будет при ошибках и повторных запросах.

VueИнтерфейс на Vue

Начнём с небольшого меню. Разберём реактивность, компоненты, формы и страницы. Научимся хранить общее состояние в Pinia и делить код на понятные части.

Go + VueПриложение целиком

Подключим интерфейс к Go API. Сделаем каталог, корзину, историю заказов и кабинет оператора. Добавим тесты и соберём приложение с Vue, Go и PostgreSQL.

Нужно ли уже знать Go?

Нет. Начнём с установки и первых программ. Опыт с переменными, условиями и циклами поможет освоиться быстрее. Для части с Vue полезны основы HTML, CSS и JavaScript.

Будет только сервер или интерфейс тоже?

Соберём обе части. Сначала Go API и базу PostgreSQL, затем интерфейс на Vue. В проекте будут каталог, корзина, заказы и кабинет оператора.

Если уже проходил другие ваши курсы?

Малая часть базовых объяснений встречается в наших курсах версий Pro и ниже. Они оставлены здесь, чтобы нужные основы были под рукой.

Можно ли пройти всё с телефона?

С телефона можно читать объяснения. Для работы с Git, Docker, базой данных и проектом нужен компьютер.
