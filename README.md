# Страницы курса на Stepik

## Алгоритмы: от идеи к инструкции

Модуль 02, урок 02: девять страниц `go-mini-module-02-lesson-02-step-01.html`
— `...step-09.html`. Урок Stepik: `2706556`, unit `2746571`, курс `305666`.
Запуск: `STEPIK_PREVIEW_PORT=8768 node scripts/preview.mjs`, затем
`http://localhost:8768/algorithms`. Можно открыть и отдельные HTML-файлы.

Опыты: открывающийся корпус Find с перемоткой выполнения, кофейный автомат
с перестановкой команд и видимыми последствиями, две ветки заказа с молоком,
повторение с отдельными счётчиками напитков и проверок, застрявший указатель
поиска и его исправление, конструктор псевдокода с четырьмя проверочными примерами.
Предметы и анимации нарисованы самостоятельно в SVG/CSS, без внешних библиотек.
Белая поверхность чтения, крупная теория и отдельные цветовые акценты опытов.
Ввод и управление доступны с клавиатуры, перестановка не требует drag-and-drop.
Анимации конечные и учитывают `prefers-reduced-motion`; смена параметров или шага
останавливает предыдущий запуск. Ошибочное повторение ограничено тремя проверками
только в учебном показе: это явно объяснено, настоящий бесконечный цикл не запускается.

Нативные задания — шаги 03, 06, 09: выбор, число, выбор, по 10 баллов.
Локальная проверка не отправляет ответы и не начисляет баллы Stepik.
`node scripts/export-algorithms-tasks.mjs` готовит только определения проверок
в игнорируемую `.local-publication/algorithms-tasks.json`; обращений к API нет.
`node scripts/export-algorithms.mjs` экспортирует весь урок: теория нативным
HTML, шесть измеренных интерактивных iframe и три нативных задания без
дублирующих полей ответа. План — `.local-publication/algorithms.json`.
Во встроенной версии результаты поиска и четыре проверки конструктора
открываются в диалоге; полная страница сохраняет исходную композицию.
Размер окна стабилен на разных ширинах и состояниях без обрезания документа.

`node scripts/publish-algorithms.mjs` — read-only проверка владельца, урока
и пустой структуры. Флаг `--apply` разрешает загрузку. Скрипт проверяет точные
файлы GitHub Pages, сохраняет резервную копию и журнал ID, не создаёт дубли
при повторном запуске, проверяет 30 баллов и доступность без платного плана.
Публичность курса и черновик урока сохраняются. Содержимое первого урока
проверяется отдельно и не изменяется.

Проверка: `PLAYWRIGHT_MODULE=/path/to/playwright-core/index.mjs node scripts/check-algorithms.mjs`.
Нужен установленный Chrome; для другого пути используется `CHROME_PATH`.
Проверяются все сцены, неверные и верные ответы, отмена и завершение анимаций,
пустые запросы, регистр, отсутствие совпадений, 0–6 заказов, отдельные шаги цикла,
обычная и встраиваемая версии, ширины 320–1280 px. Снимки — во временном каталоге.
`node scripts/check-algorithms-layout.mjs` проверяет нативный поток и реальные
размеры cross-origin iframe, результаты, диалоги и промежутки до теории на шести
ширинах. После загрузки `--published` использует HTML, сохранённый ответом
Stepik API, с фактической очисткой разметки платформой.

При разработке изучены:

- [Mechanical Watch](https://ciechanow.ski/mechanical-watch/) — разбор предмета и видимые внутренние части.
- [Red Blob Games](https://www.redblobgames.com/making-of/line-drawing/) — единое состояние управления и диаграммы.
- [Sight & Light](https://ncase.me/sight-and-light/) — объяснение через наблюдаемую ошибку и исправление.
- [Learnable Programming](https://worrydream.com/LearnableProgramming/) — состояние и ход выполнения рядом с инструкцией.
- [Seeing Theory](https://seeing-theory.brown.edu/basic-probability/index.html) — изменение параметров и наблюдение результата.
- [Explorable Explanations](https://explorabl.es/) — примеры интерактивных объяснений.
- [Spring Physics](https://www.joshwcomeau.com/animation/a-friendly-introduction-to-spring-physics/) — короткое затухающее перемещение вместо постоянного движения.
- [Image Kernels](https://setosa.io/ev/image-kernels/) — связь локальной операции с её результатом.
- [Distill](https://distill.pub/2016/misread-tsne/) — наблюдение промежуточных состояний при изменении параметра.

## Новая версия урока об информации (v2)

Опубликована в [уроке Stepik](https://stepik.org/lesson/2706555/step/1?unit=2746570):
все 10 шагов обновлены с сохранением ID, четыре нативных задания проверены
по API — по 10 баллов, суммарно 40. Все шаги включены, дополнительных
платных планов не требуют. Публичность и статус черновика курса не изменены.

Просмотр: `STEPIK_PREVIEW_PORT=8767 node scripts/preview.mjs`, затем
открой `http://localhost:8767/information-v2`.
Публичный просмотр страниц после загрузки:
`https://zak618.github.io/stepik-course-pages/go-mini-module-02-lesson-01-v2-preview.html`.

Десять страниц `go-mini-module-02-lesson-01-v2-step-01.html` — `...step-10.html`
используют `assets/go-mini-information-v2-content.js`,
`assets/go-mini-information-v2.js` и `assets/go-mini-information-v2.css`.
Просмотр переключает страницы без iframe: высота следует за содержимым.
Сверху доступны ширина телефона и открытие отдельной страницы.

Рассказ начинается с сообщения другу и связывает темы переходами.
Композиции чередуются: вопрос и опыт, разбор перед опытом, объяснение рядом
с предметом. Вместо условных панелей — два компьютера с передачей байтов,
шкафчики с кодами, весы, бирка, упаковка числа, коробки байтов, принтер UTF‑8
и картотека Go-шечка Find. Цвет подчёркивает состояния и разряды.
Основное объяснение открыто; дополнительные нюансы раскрываются отдельно.
В опыте Find ищем заметки про циклы. Одна кнопка запускает конечный проход
лупы по четырём цветным заметкам; совпадения собираются в папку результатов.
Запросы `цикл`, `функц` и `пицца` дают 2, 1 и 0 записей. Регистр не учитывается,
пробельный запрос просит уточнить тему. При изменении ввода старый поиск отменяется.

Анимации конечные, учитывают `prefers-reduced-motion`; действия доступны
с клавиатуры. Ввод экранируется. Ответы и прогресс Stepik не отправляются,
Go в браузере не запускается. В Stepik рассказ экспортируется нативным HTML,
а в iframe остаются только опыты: `?panel=scene|carry|rgb`.
У встроенной версии байты доступны в диалоге с листанием, шкафчики — группами
по четыре; в поиске все четыре заметки видны сразу. Коробки тоже листаются
группами по четыре; все восемь по-прежнему участвуют в подсчёте.
Результаты проверки ответов открываются в диалоге внутри опыта;
найденные заметки остаются в папке под поиском.
Полные страницы сохраняют все данные. Это ограничивает высоту окна без
обрезания документа или ответов. Размеры предметов и строк статуса стабильны:
ответ не раздвигает встроенное окно и не требует запаса на пустой экран.
Видимый заголовок зачётных вопросов — «Проверим знания»; оценка остаётся
в нативных настройках Stepik и не добавляется в заголовок.

Экспорт: `node scripts/export-information-v2.mjs`. План и измерения разных
ширин/состояний записываются в игнорируемую `.local-publication/information-v2.json`.
Загрузка: `node scripts/publish-information-v2.mjs --apply`; без `--apply`
выполняется только проверка доступа. Скрипт сохраняет ID всех десяти шагов,
проверяет точные файлы GitHub Pages, создаёт резервную копию, сохраняет
публичность и статус черновика курса. Другие уроки не меняются.

Четыре нативных задания Stepik (шаги 04, 05, 07 и 09) оцениваются
**по 10 баллов, суммарно 40**. Типы: число, одиночный выбор, число,
одиночный выбор. Локальные упражнения не начисляют баллы и не заменяют зачёт.
Нативные ответы и комментарии проверки сохранены в экспортёре.

Для загрузки нужен владелец курса WEB HACKER (647088271).
Текущее приложение использует **client_credentials**, а не authorization-code:
`node scripts/authorize-webhacker.mjs --client-credentials` получает доступ
по уже настроенной `.env.stepik`, проверяет ID пользователя и владельца курса.
Повторный переход по браузерной ссылке авторизации для этого приложения не нужен.
Проверенная сессия сохраняется отдельно в игнорируемую
`.env.stepik-webhacker-session`; чужая `.env.stepik-session` не заменяется.
Режим callback без флага оставлен только для отдельных приложений,
настроенных именно на authorization-code. Ключи в публикацию не входят.

Проверка: `node scripts/check-information-v2.mjs` с `playwright-core` и Chrome.
При внешней установке передай `PLAYWRIGHT_MODULE` — абсолютный путь к `index.mjs`.
Проверяются взаимодействия всех десяти сцен, кодировки, смена шагов во время
анимации и ширины 320, 390, 768 и 1280 px; снимки сохраняются во временный каталог.
`node scripts/check-information-v2-layout.mjs` дополнительно проверяет нативную
разметку с cross-origin iframe, расстояние до следующего абзаца, отсутствие
внутреннего скролла, диалоги и раскрытые состояния на шести ширинах 320–1024 px.
После загрузки флаг `--published` использует сохранённый ответ API Stepik,
включая его реальную очистку HTML/CSS, а не исходный экспорт.

Идеи подачи изучены на [Ciechanowski](https://ciechanow.ski/mechanical-watch/),
[Red Blob Games](https://www.redblobgames.com/pathfinding/a-star/introduction.html)
и [Sight & Light](https://ncase.me/sight-and-light/).
Тексты, код и рисунки урока созданы самостоятельно.

## Предыдущая версия урока (v1)

Загружен в [урок Stepik](https://stepik.org/lesson/2706555/step/1?unit=2746570):
10 шагов, из них 4 проверяемых задания. Все шаги включены и не требуют
платного плана. Статус черновика и публичность всего курса сохранены.

Урок «Как компьютер представляет информацию»: **10 отдельных HTML-страниц**
`go-mini-module-02-lesson-01-step-01.html` — `...step-10.html`.
Общий просмотр: `go-mini-module-02-lesson-01-preview.html`.

Запуск: `STEPIK_PREVIEW_PORT=8767 node scripts/preview.mjs`.
Открой `http://localhost:8767/information`.
В боковом меню переключаются шаги; сверху можно включить ширину телефона
или открыть отдельную страницу. Высота iframe в локальном просмотре
подстраивается под содержимое, включая раскрытые объяснения.
Внизу длинного шага есть переходы назад/вперёд; при смене шага просмотр
возвращается к началу текста. На широком экране меню шагов остаётся доступным.

| Шаг | Содержание и взаимодействие |
| --- | --- |
| 01 | Слово → реальные байты UTF‑8; группировка по видимым знакам |
| 02 | Тактильные переключатели, все 2ⁿ комбинации, задача о пяти шкафчиках |
| 03 | Грузики 16/8/4/2/1, сумма и связанный ползунок |
| 04 | Прочитать двоичное число, локальная проверка и новые примеры |
| 05 | Записать число пятью битами с клавиатуры или кнопками |
| 06 | Байтовая карточка, граница 256, пошаговый двоичный перенос |
| 07 | Наборы байтов, перевод в биты |
| 08 | Символ → Unicode → UTF‑8; цветовая разметка служебных битов |
| 09 | Один байт как число, текст и яркость; отдельный RGB-микшер |
| 10 | Go-шечка Find, учёт регистра, пошаговая проверка записей, подробный замысел проекта |

Общие файлы: `assets/go-mini-information.{css,js}`, отдельный рассказ
`assets/go-mini-information-story.js` и
`assets/go-mini-information-preview.{css,js}`. Внешних зависимостей нет.
Основной рассказ на каждой странице открыт: постановка вопроса перед опытом,
затем подробный разбор с примерами, ошибками и переходом к следующей теме.
В `details` спрятаны только дополнительные нюансы, не обязательное объяснение.
Сценарии упражнений, цвета и контрпримеры встроены в последовательный рассказ,
а не заменяют его. Учебные материалы написаны самостоятельно, без копирования лекций.
Go-шечка Find раскрыт как будущий консольный поиск по коллекции записей: вход, вывод,
правило вхождения, регистр, роль переменных/условий/циклов/срезов/функций, проверки
и границы базовой версии. Терминал — подписанный пример будущего поведения.
Текущий браузерный опыт при пустом запросе показывает все записи; в базовом
консольном проекте планируется просить уточнить пустой/пробельный запрос.
Работают клавиатура и `prefers-reduced-motion`; введённый текст экранируется.
Это **локальный прототип**: проверки не отправляют ответы и не меняют прогресс
Stepik. Go-шечка Find здесь иллюстрируется на JavaScript, Go в браузере не запускается.
В Stepik основной рассказ размещается нативным HTML, а опыты — отдельными
встроенными панелями. Параметр `?panel=scene|locker|carry|rgb|trace` показывает
только соответствующий интерактив. Высота рассчитывается по его состояниям
на ширинах 320, 390, 768 и 1024 px, а не по всему длинному рассказу.
В компактном опыте первого шага показаны карточки первых шести видимых знаков,
для составного знака — первые четыре байта; счётчик учитывает весь ввод.
Самостоятельная HTML-страница по-прежнему показывает полные данные.

Шаги 04, 05, 07 и 09 имеют нативные задания Stepik: число, выбор, число и выбор.
Нативная проверка строки требует на этом аккаунте платный план `basic_paid`,
поэтому зачёт пятого шага использует бесплатный выбор двоичной записи.
Собирать запись вручную всё ещё можно в интерактивном тренажёре.
Тренажёры не подменяют зачёт: в конце этих шагов есть отдельное задание.
Экспорт: `node scripts/export-information.mjs` с теми же параметрами Playwright,
что и проверки ниже. Генерируемые материалы и резервные копии находятся
в игнорируемой `.local-publication/`.
Загрузка: `node scripts/publish-information.mjs --apply`. Скрипт проверяет
готовность GitHub Pages, аккаунт 647088271, курс 305666, урок 2706555,
не заменяет посторонние шаги, не меняет публичность или статус черновика курса
и проверяет, что каждый шаг доступен без платного плана.
Для него используется уже настроенная локальная `.env.stepik-session`;
ключи и токены не входят в репозиторий.

Браузерные проверки: `node scripts/check-information.mjs` (нужен `playwright-core`
и Chrome). Если пакет установлен вне проекта, передай `PLAYWRIGHT_MODULE`
с абсолютным путём к его `index.mjs`; адрес сервера можно поменять через
`STEPIK_PREVIEW_ORIGIN`, путь Chrome — через `CHROME_PATH`.

Материалы для проверки понятий и педагогического подхода:
[CS50, вводная лекция](https://cs50.harvard.edu/x/notes/0/),
[Unicode: кодировки UTF](https://www.unicode.org/faq/utf_bom.html),
[Go: строки, байты и символы](https://go.dev/blog/strings),
[спецификация Go: строки](https://go.dev/ref/spec#String_types).
Это не перевод лекции CS50 и не воспроизведение индивидуальной манеры преподавателя:
используется общий приём «вопрос → опыт → объяснение → применение».

Страницы называются по шаблону:

`<курс>-module-<номер>-lesson-<номер>-step-<номер>.html`

Например: `go-mini-module-01-lesson-01-step-01.html` — приветствие для первого шага первого урока первого модуля курса «Go-шечка (mini)».

После публикации GitHub Pages эту страницу нужно вставить в содержимое шага Stepik как iframe, чтобы она открывалась прямо в уроке:

```html
<iframe
  src="https://zak618.github.io/stepik-course-pages/go-mini-module-01-lesson-01-step-01.html"
  title="Добро пожаловать на курс Go-шечка (mini)"
  width="100%"
  height="620"
  style="border:0;display:block;max-width:100%"
  loading="lazy">
</iframe>
```

Не заменяй `src` на обычную ссылку: iframe показывает страницу прямо внутри шага.

## Локальные страницы первого урока

Запуск: `node scripts/preview.mjs`, затем открой `http://localhost:8766/`.
В просмотре есть переключатель шагов и ширины телефона.

| Шаг | Файл | Содержание |
| --- | --- | --- |
| 03 | `go-mini-module-01-lesson-01-step-03.html` | Выбор источника автоматически заполняет видимый ответ; свой текст сохраняется при смене источника |
| 04 | `go-mini-module-01-lesson-01-step-04.html` | Раскрывающиеся правила и кнопка «Договорились» |
| 05 | `go-mini-module-01-lesson-01-step-05.html` | Карта направлений, поиск, фильтр бесплатных, личный маршрут |
| 06 | `go-mini-module-01-lesson-01-step-06.html` | Слайдер перехода в первый урок второго модуля |

Общие файлы находятся в `assets/`. При будущей публикации HTML нужно загружать вместе с ними.
`go-mini-embed.js` включает компактную вёрстку внутри iframe, а `go-mini-embed.css`
убирает фон по краям и задаёт ограниченную высоту интерактивных состояний.

Правила используют один открытый пункт, встроенный каталог — постраничный вывод,
а слайдер в финале переводит всю страницу в урок 2706555 (unit 2746570).
Неполный жест возвращает стрелку назад; Enter позволяет продолжить с клавиатуры.
Нельзя добавлять `overflow:hidden` всему документу, чтобы замаскировать обрезанный контент.

Изображения сохраняют пропорции; используются на карте, в каталоге и в карточке курса.
Карта содержит 37 опубликованных курсов каталога WEB HACKER, проверенного 13.11.2026,
и текущий курс 305666 под будущим названием «Go-шечка (mini)». Остальные черновики не показаны.
Названия, бесплатность и требования к старту сверены с API Stepik; порядок по темам — рекомендация.
Версии курсов и пакеты показаны как варианты, а не обязательные последовательные покупки.

Ответ анкеты не отправляется из iframe на сервер: ученик копирует его в нативное поле
шага Stepik «Свободный ответ» и отправляет средствами Stepik.
Согласие с правилами и выбранные курсы сохраняются в браузере и не меняют прогресс Stepik.
Страницы не содержат API-ключей.
