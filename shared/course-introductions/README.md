# Единое введение WEB HACKER

Оформление взято из Go-шечки mini. Название, темы, требования и переход к
следующему уроку задаются для каждого курса. Mini служит образцом;
Go pro и Go Pro MAX исключены из публикации.

## Где что лежит

| Путь | Для чего |
| --- | --- |
| `copy.mjs` | Текст о темах и требованиях каждого курса по ID Stepik |
| `catalog.mjs` | Постоянные имена папок, имена страниц и версия сборки |
| `templates/` | Общие HTML приветствия, Telegram, знакомства, правил, карты и старта |
| `base.css`, `embedded.css` | Оформление страниц и встраивания |
| `interactions.js` | Выбор источника, копирование ответа, согласие с правилами, карта и слайдер |
| `study.css` | Оформление советов по практике |
| `preview.css`, `preview.js` | Только оболочка просмотра для автора |
| `../../courses/` | Готовые страницы, разложенные по курсам |
| `../../scripts/course-introductions/` | Чтение, сборка, проверка и публикация |

В `courses/<ID>-<название>/introduction/` всегда семь понятных файлов.
Они генерируются: сначала измените общий шаблон или `copy.mjs`, затем пересоберите.
Карта и обложки используют уже существующий общий каталог, без отметки «вы здесь».
Платные курсы в карте открываются по авторской ссылке `https://stepik.org/a/ID`, бесплатные по обычной ссылке курса.
Советы «Как будем учиться» публикуются обычным HTML Stepik, без фрейма,
фиксированной высоты и внутреннего скролла. `04-how-to-learn.html` нужен для просмотра.

## Команды из корня репозитория

```sh
node scripts/course-introductions/snapshot.mjs
node scripts/course-introductions/build.mjs
node scripts/course-introductions/preview.mjs
```

Просмотр: <http://localhost:8795/>. В нём можно выбрать курс, раздел и ширину телефона.
Снимки с исходными данными и журнал публикации остаются в игнорируемой
`.local-publication/unified-intros-preview-20261116/`, а не в публичных файлах.

## Что не меняем

Публикация меняет только оформление существующих бесплатных текстовых шагов.
ID существующих шагов, их порядок относительно друг друга, задания, баллы,
настройки и доступ сохраняются.
Telegram и правила теперь находятся в разных шагах. В 29 введениях добавлен
отдельный бесплатный текстовый шаг с правилами; порядок существующих заданий сохранён.
Прямые ссылки mini ведут в папки модулей, без промежуточной страницы.
У приветствия заменяется только начальный общий текст. Дублирующий блок
«Перед началом» убран; требования остаются в советах по обучению.
Особые материалы, в том числе теория путешествия по Уралу и состав пакетов, сохраняются.
Истории, версии, спонсоры, подборки ссылок и другие особые материалы не заменяются
универсальным текстом. Существующие вопросы Stepik и их поля ответа сохраняются.

Новые страницы подготовлены для общего оформления, но отдельные файлы не
означают добавление семи новых шагов в каждый курс. Используются подходящие
шаги, которые уже есть. Сборка и локальный просмотр сами ничего не публикуют.
