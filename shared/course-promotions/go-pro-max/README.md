# Билет на Go Pro MAX

Реклама отдельным бесплатным текстовым шагом во введении и в конце курса.
Приветствие, карта, задания, ответы и баллы сохраняются.
Сам Go Pro MAX исключён, реклама не ведёт на курс из него же.

```sh
node scripts/course-promotions/preview.mjs
```

Просмотр: <http://localhost:8814/>. Выберите курс и размер экрана.
`card.html?audience=general` показывает 10%, `card.html?audience=go` показывает 20%.
Обложка взята из курса. Фон белый, акценты сиреневые.

В `offer.mjs` находятся ссылка и варианты скидки. Для 10% задан GOSHECHKAMAX.
Для 20% согласован GOSHECHKAMAX20, он используется в Go mini и pro.
Оба кода предоставлены автором. Проверка покупки не выполнялась.
Макет не создаёт промокоды и не меняет условия оплаты в Stepik.

Билет стирается мышью или пальцем. После стирания можно скопировать код.
Enter и пробел открывают билет с клавиатуры. Без JavaScript код виден сразу.
При запрете буфера обмена остаётся ручное выделение. Учитывается reduced motion.

Локальный сервер выдаёт только файлы макета и список названий курсов.
Он не читает ключи, не делает запросов к Stepik и не умеет публиковать изменения.

## Публикация

Скрипты находятся в `scripts/course-promotions/`. Все данные доступа читаются
только из локальной сессии WEB HACKER `647088271`. Другой аккаунт не принимается.

```sh
node scripts/course-promotions/snapshot.mjs
node scripts/course-promotions/build.mjs
PLAYWRIGHT_MODULE=/path/to/playwright-core/index.mjs node scripts/course-promotions/check.mjs
node scripts/course-promotions/publish.mjs
```

Перед `--apply` загрузите готовые файлы в GitHub Pages и дождитесь публикации.
Публикатор сверяет содержимое каждого файла на хостинге с локальным.

```sh
node scripts/course-promotions/publish.mjs --apply --course=135466
node scripts/course-promotions/publish.mjs --apply
node scripts/course-promotions/publish.mjs --verify
```

`offer-10.html` и `offer-20.html` генерируются из `card.html`. У них одинаковая
высота 400 px, правильный код есть даже без JavaScript. После начала публикации
обычная сборка запрещена: версия плана и журнала должна совпадать.
Для правки только оформления или поведения используйте
`node scripts/course-promotions/build.mjs --assets-only`.
Этот режим сохраняет адреса фреймов, позиции и журнал, но обновляет кеш CSS/JS.
Скрипт откажется менять уже составленный план шагов.

План, исходные данные, ID новых шагов и проверка лежат в закрытой
`.local-publication/go-max-course-promotions-20261126/`. Журнал позволяет
продолжить загрузку без дублей. Неизвестный результат POST требует проверки,
повторное создание вслепую запрещено. Ничего не удаляется.

В обычном введении шаг стоит перед «Начинаем», если такой переход есть,
иначе в конце введения. В финальном уроке он добавляется последним.
В трёх пакетах введение и финал совпадают, поэтому нужен один шаг на пакет.
Для GitHub mini создаётся отдельный последний урок «Что дальше»:
общий с другими курсами урок о подмодулях не меняется.

Итого 39 курсов, 75 новых шагов и один новый урок. Из них четыре шага
со скидкой 20%: начало и конец Go mini и pro. Остальные со скидкой 10%.

После полной проверки `node scripts/course-promotions/export.mjs` сохраняет
ссылки и ID размещений в `publication.json`. В этот файл не попадают ключи,
снимки заданий, ответы учеников или настройки аккаунтов.

Проверка непосредственно в Stepik, без отправки ответов и изменения прогресса:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright-core/index.mjs node scripts/course-promotions/check-live.mjs --courses=135466,305666,300562,218158
```

Она проверяет настоящие файлы на хостинге, оба кода, a-ссылку, белый фон,
раскрытие билета с клавиатуры и отсутствие скролла на четырёх размерах экрана.
